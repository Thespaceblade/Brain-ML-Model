# Demo sample images

Small MRI samples used by the Streamlit app for **Use Test Image**.

- `bleeding/` — tumor / bleeding-positive examples
- `no_bleeding/` — no-tumor / negative examples

These are a tiny subset of the [Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) for UI demos only.
